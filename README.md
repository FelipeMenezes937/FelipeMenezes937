### HeapSec Antivirus

Scanner antivírus **100% local** por análise estática com múltiplos motores de detecção heurística. Desenvolvido em Java puro, sem dependências externas.

**Destaques técnicos**
- Processamento de ~1.800 arquivos/s com `ForkJoinPool`
- Motores: Entropia Shannon · Aho-Corasick · Parsing PE nativo
- 60+ padrões: password stealers, RATs, cryptominers, bankers
- Proteção contra path traversal, symlink attacks e zip bombs
- **Zero dependências** — funciona completamente offline
